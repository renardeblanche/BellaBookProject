\chapter{校勘记录}
本附录汇总需要实质修正、条件补充或术语说明的条目；正文相应处均保留“校勘”脚注。
\begin{enumerate}
  \item 第一章第 2 条：Bézout 恒等式有一处排印错误，已改为 $d(x)=u(x)f(x)+v(x)g(x)$。
  \item 第一章“多项式函数”段：将“数域/有穷多个元素”的对举改写为“无限域/有限域”，避免传统“数域”术语与有限域例子之间的混用。
  \item 第二章矩阵乘法第 7 条：补明 $AB-BA=E$ 不可能的结论是在特征 $0$（更一般地，特征不整除 $n$）的语境下成立。
  \item 第三章第 1 节“例 2”：四元素加法表除 B 外还违反 C，不能证明 B 独立；已更换为只破坏 B 的反例。
  \item 第三章第 1 节“例 7”：所列例子同时违反公理 F 与 G，不能证明 G 的独立性；已更换为仅违反 G 的严格反例。
  \item 第三章第 2 节关于循环相邻和：由行列式 $D=2$ 推出线性无关时，补出 $\operatorname{char}F\ne2$ 的条件。
  \item 第三章第 4 节：说明“有限空间 / 有基底空间 / 自由空间”的旧式术语与现代模论“有限生成模 / 循环子模内直和 / 自由模”并不完全一致；正文仍沿用既有称谓。
  \item 第四章非线性变换例 1：数值反例依赖存在 $k\ne0,1$；为排除二元域的无关例外，明确取 $F=\mathbb R$。
  \item 第四章 $AB-BA=E$：与第二章一致，补明有限矩阵不可能性的特征条件。
  \item 第五章等价关系第 2 例：余数分类的符号书写较含混，改用模 $4$ 同余类直接验证；结论与反例保持不变。
  \item 第六章群元阶的单位根例：“$mn/d$ 次单位根”按“满足 $x^{mn/d}=1$”理解，并不表示其精确阶必为 $mn/d$。
  \item 第七章“数域”例：含 $\sqrt[3]2$ 的三维有理系数对象记号与系数说明不一致；据上下文改为 $\mathbb Q(\sqrt[3]2)=\mathbb Q[\sqrt[3]2]$。
  \item 第七章最大理想：将“不可约 $p(x)\in F[x]$ 所生成的最大理想”所在环由误排的 $F(x)$ 改为 $F[x]$。
  \item 第七章因子分解：“素元”的定义对应现代通常所称的“不可约元”，而非一般意义下更强的 prime element；正文保留“素元”，并加术语校勘。
  \item 第七章 $\mathbb Q[x]$ 中的 $(2,x)$：补明因为 $2$ 在 $\mathbb Q[x]$ 中可逆，该理想等于整个 $\mathbb Q[x]=(1)$，以免把它误读为非平凡主理想。
\end{enumerate}
